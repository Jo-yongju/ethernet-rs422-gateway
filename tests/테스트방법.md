Windows / MinGW GCC

From the project root:

gcc common\crc16.c common\protocol.c tests\protocol_test.c -Icommon -std=c11 -Wall -Wextra -Wpedantic -o protocol_test.exe
.\protocol_test.exe

WSL / Linux GCC

gcc common/crc16.c common/protocol.c tests/protocol_test.c \
  -Icommon -std=c11 -Wall -Wextra -Wpedantic \
  -o protocol_test

./protocol_test

Result: 9 passed, 0 failed

Later in STM32CubeIDE

The reusable files are:

crc16.h
crc16.c
protocol.h
protocol.c

protocol_test.c is only for the PC-side unit test.

Do not put HAL calls inside crc16.c or protocol.c.
HAL/UART/SPI/Ethernet code will call these modules from the STM32 application layer.
