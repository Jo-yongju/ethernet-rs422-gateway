Later in STM32CubeIDE

The reusable files are:

crc16.h
crc16.c
protocol.h
protocol.c
stream_parser.h
stream_parser.c

The files under tests/ and firmware/f429_remote_node/Tests/ are only for PC-side unit tests.

Do not put HAL calls inside the reusable protocol modules.
HAL/UART/SPI/Ethernet code will call these modules from the STM32 application layer.
